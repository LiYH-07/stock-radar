# 📡 快訊雷達 (Stock Radar)

> **美股・台股訊號即時追蹤與每日總結儀表板**
> Google Apps Script (GAS) API + Google Sheets 後端，搭配 GitHub Pages 託管的晶透玻璃風格 (Glassmorphism) PWA 前端。

---

## 🌟 功能特色

- 💎 **晶透玻璃視覺**：磨砂玻璃質感、視差 3D 傾斜、動態卡片。
- 📊 **美股・台股雙市場**：同時讀取兩份 Google 試算表（`美股紀錄` / `台股紀錄`），合併後依時間倒序顯示。
- 📈 **即時股價與漲跌幅**：後端呼叫 Yahoo Finance，台股自動判斷上市（`.TW`）或上櫃（`.TWO`），並有 60 秒快取。
- 🔒 **密碼防護**：API 需帶正確密碼才會回傳資料，避免未授權讀取與消耗額度。
- 🌓 **雙主題與漲跌配色**：
  - 主題：冰霧初融（亮色）／冰融暖綻（暗色），預設跟隨系統，可手動切換。
  - 配色：紅漲綠跌（台股習慣）或綠漲紅跌（美股習慣）。
- ⚡ **預設只載入最近 1 天**：以當日訊號為主，減少載入時間；可改選 3／7／30 天，或自訂日期區間。
- 📱 **PWA**：可安裝到手機主畫面，獨立全螢幕執行（Android Chrome / iOS Safari）。
- 📅 **雙檢視**：
  - **訊號列表**：依時間倒序顯示最新訊號（最多 150 筆）。
  - **每日總結**：依日期、市場、訊號分類，統計觸發次數與首次觸發價格。

## 📋 試算表格式

後端依**欄位位置**讀取（第 1 列為標題，從第 2 列開始），其餘欄位會被忽略：

| 欄位 | 內容 | 範例 | 說明 |
| :-- | :-- | :-- | :-- |
| **A** | 時間 | `2026-10-09 09:06:51` | 日期時間 |
| **B** | 股票 | `6223_旺矽` / `COIN` | 台股用「代號_名稱」；美股填代號即可 |
| **C** | 價格 | `5595` / `173.81` | 訊號觸發時的價格 |
| **D** | 訊號 | `抄底` / `買入` / `減1` | 訊號類型 |

預設分頁名稱為 `美股紀錄`、`台股紀錄`，可在 `Code.gs` 的 `CFG.SOURCES` 修改。

## 🚀 部署步驟

### 1. 後端（Google Apps Script）

1. 開啟試算表 → **擴充功能 → Apps Script**，貼上 `Code.gs`。
2. 修改 `CFG`：
   - `PASS`：**改成你自己的存取密碼**（設為 `''` 則不驗證）。
   - `SOURCES`：美股、台股若在不同試算表，填入各自的 Sheet ID（網址 `/d/` 與 `/edit` 之間那串）；留空代表使用腳本所綁定的試算表。
   - `MAX_ROWS`：每份 Sheet 只讀最後幾列（預設 8000），查不到較早日期時可調大。
3. **部署 → 新增部署作業 → 網頁應用程式**：執行身分選「我」，存取權選「所有人」。
4. 複製以 `/exec` 結尾的網址。
5. 之後修改程式碼，需要「管理部署作業 → 編輯 → 新版本」才會生效。

### 2. 前端（GitHub Pages）

1. 把下列檔案上傳到同一個 GitHub Repository 的同一層：`index.html`、`manifest.webmanifest`、`sw.js`、所有圖示與背景圖。
2. 編輯 `index.html`，填入後端網址：
   ```js
   const API = 'https://script.google.com/macros/s/xxxxxxxx/exec';
   ```
3. Repository **Settings → Pages**，選擇分支發布。
4. 首次開啟網站時輸入密碼，密碼會存在該瀏覽器的 localStorage。

> 若 `API` 留空，頁面會顯示範例資料，方便先預覽介面。

## 📱 安裝為 App

| 平台 | 做法 |
| :-- | :-- |
| **Android Chrome** | 開啟網站，等待數秒後從選單選「安裝應用程式」 |
| **iOS Safari** | 分享 → 加入主畫面 |

### PWA 無法安裝時的檢查清單

- 網站必須是 **HTTPS**（GitHub Pages 預設符合）。
- `index.html` 的 `<link rel="manifest">` 必須指向實際存在的 `manifest.webmanifest`。
- 圖示必須是**真正的 PNG**，且實際尺寸與 manifest 宣告一致（`icon-192.png` 為 192×192，`icon-512.png` 與 `icon-maskable-512.png` 為 512×512）。副檔名是 `.png` 但內容是 JPEG 會被 Chrome 拒絕。
- `sw.js` 要與 `index.html` 放在同一層，才能涵蓋整個站台範圍。
- 舊版捷徑可能留有快取：先移除舊的主畫面圖示再重新安裝。
- 想看具體錯誤：電腦版 Chrome → DevTools → **Application → Manifest**。

## 📂 檔案結構

```
.
├── index.html              # 前端主頁（介面、樣式、API 互動）
├── Code.gs                 # GAS 後端（讀取試算表、查詢股價）
├── manifest.webmanifest    # PWA 清單
├── sw.js                   # Service Worker（只快取站內頁面，API 不快取）
├── icon-192.png            # 192×192 圖示
├── icon-512.png            # 512×512 圖示
├── icon-maskable-512.png   # 512×512 可遮罩圖示（內容縮在安全區內）
├── apple-touch-icon.png    # 180×180 iOS 主畫面圖示
├── bg-light.jpg            # 亮色背景
├── bg-dark.jpg             # 暗色背景
└── README.md
```

## 🔐 安全提醒

- 密碼寫在 `Code.gs` 中，並以網址參數傳送。這只能擋住一般的路人，**不是強式驗證**。
- 請務必修改預設密碼，**不要把真實密碼與 Sheet ID 提交到公開 Repository**。
- 若 Repository 是公開的，建議把真實 `PASS` 只放在 Apps Script 內，不要同步到 GitHub。
